# AWS Cloud Security Dashboard

## Overview

A cloud-native security posture management platform that continuously scans AWS resources and identifies security misconfigurations across IAM, S3, EC2 and Security Groups.

## Features

- IAM Security Analysis
- S3 Security Analysis
- Security Group Scanning
- Compliance Dashboard
- Security Alerts
